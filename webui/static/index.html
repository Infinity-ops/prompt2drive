  1. Agent 1 Generator

    Turns your prompt into a validated scenario spec.

  2. Engine CARLA

    Runs the spec in the simulator and captures frames and a state log.

  3. Agent 2 Verifier

    Checks the frames and log against your prompt, predicate by predicate.

  4. Agent 3 Reflector

    If a check fails, writes a targeted correction and sends it back to the Generator.
